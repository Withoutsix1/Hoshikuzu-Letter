# 音乐试听

以下为《星屑信》的三段游戏配乐试听，每段约 45 秒。曲目由项目通过 Gemini 网页音乐生成功能创作，包含 AI 生成音乐；试听名仅用于展示，不代表正式原声曲名。

| 试听 | 氛围 | 文件 |
| --- | --- | --- |
| 春日常景 | 新学期的日常 | [播放或下载](daily-preview.mp3) |
| 静谧时分 | 安静的独处 | [播放或下载](quiet-preview.mp3) |
| 暖意片刻 | 轻柔的相处 | [播放或下载](warm-preview.mp3) |

试听从项目配乐中截取，加入淡入与淡出。原曲包含平台用于识别 AI 生成内容的数字水印，制作试听未进行水印移除处理。

作者已确认生成时年满 18 周岁，未参考他人音乐。根据 [Gemini 音乐帮助](https://support.google.com/gemini/answer/16901237?hl=zh-Hans)和 [Google 服务条款](https://policies.google.com/terms/embedded?hl=en-US)整理来源与使用说明；Google 不主张生成内容的所有权，不代表平台保证输出具有排他版权。
