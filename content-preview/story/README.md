# 作品介绍

## 星屑信

四月，新学期开始。高二学生月白秋一的日常，在同好会的闲聊、放学后的相处和朋友们的奇思妙想中慢慢展开。

当一群高中生走进星时山的旧邮局，一封信能否跨越时间，成了他们无法轻易放下的疑问。看似遥远的不可思议，与眼前真实的相处交织在一起。那些还没来得及说出口的话，也渐渐有了想要送达的人。

《星屑信》是一部正在制作中的日式校园恋爱视觉小说。故事以秋一的视角展开，在校园日常中描写彼此的试探、关心与靠近，也让书信成为连接相遇与时间的线索。
