# 主要人物

## 月白秋一

**高二学生 · 故事的主人公**

习惯把见闻记在笔记本里，遇到不明白的事，总想多问一句、再确认一次。他认真，也有些执拗；熟悉起来后，会开玩笑，也会为朋友的奇思妙想较真。只是轮到说清自己的心意时，这份直率便常常打了折扣。

## 比叡雏

<img src="../../showcase/sprites/hina-standard.jpg" width="240" alt="比叡雏标准立绘展示版">

**高二转学生 · 把日常变成小小冒险的人**

樱粉色双马尾的转学生，活泼，爱点心，也热衷于给平凡的小事添上郑重其事的名字与仪式。她的想法常常先于解释一步，把身边的人卷进新的计划。比起计划本身能否成功，她更在意朋友们是否愿意陪她一起完成。

## 椿静夜

<img src="../../showcase/sprites/shizuya-standard.jpg" width="240" alt="椿静夜标准立绘展示版">

**高三学生 · 学生会长兼风纪委员长**

做事周全，待人克制，是让人不自觉挺直背脊的学姐。学习、运动与组织事务都能从容应对，也习惯把职责放在个人安排之前。她对规则认真，对身边的人同样认真；关心往往藏在一项已经替你安排妥当的小事里。

## 神崎琉璃

<img src="../../showcase/sprites/ruri-standard.jpg" width="240" alt="神崎琉璃标准立绘展示版">

**高三学生 · 对怪谈与故事充满好奇的学姐**

有着一头金色长发，自尊心强，也很难对有趣的传闻置之不理。喜欢怪谈与写作，越是来历不明的故事，越能勾起她的好奇。嘴上总想占得上风，行动却常比解释更诚实：还没承认自己在意，已经先一步参与其中。

## 雪丸奏

<img src="../../showcase/sprites/kanade-standard.jpg" width="240" alt="雪丸奏标准立绘展示版">

**高二学生 · 用旧相机留住日常的观察者**

银色短发，随身带着旧相机，喜欢摄影与天文。她说话直接，思路时常突然转弯，一句出人意料的发言就能改变谈话的方向。她能注意到别人忽略的细节，不过，敏锐的观察和准确的解释之间，偶尔也会隔着一段距离。
